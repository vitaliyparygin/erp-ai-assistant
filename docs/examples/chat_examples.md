# Chat Examples

The following examples demonstrate real use cases supported by the AI ERP Assistant.

---

## Vendor Information

**Question**

> Find vendor phone number.

Expected result

- Returns vendor profile
- Shows phone number
- Includes citation

---

## Purchase Order

**Question**

> What is the total amount in Purchase Order PO-2024-001?

Expected result

- Finds Purchase Order.pdf
- Returns amount: **12500 UAH**
- Includes citation
