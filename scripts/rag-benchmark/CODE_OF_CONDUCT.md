# Code of Conduct

## Our Pledge

We are committed to providing a welcoming, respectful, and inclusive environment for everyone, regardless of background, experience level, identity, or personal characteristics.

We expect all participants to:

* Be respectful and professional.
* Welcome constructive feedback.
* Assume good intent.
* Focus discussions on technical topics.
* Help create a positive community.

## Expected Behavior

Examples of positive behavior include:

* Being respectful in discussions.
* Providing constructive code reviews.
* Reporting bugs with clear reproduction steps.
* Helping new contributors.
* Respecting different opinions and approaches.

## Unacceptable Behavior

Examples include:

* Harassment or personal attacks.
* Offensive or discriminatory language.
* Trolling or intentionally disruptive behavior.
* Publishing private information without permission.
* Spam or unrelated promotional content.

## Reporting Issues

If you experience unacceptable behavior, please open a private GitHub issue or contact the project maintainer.

All reports will be handled confidentially whenever possible.

## Enforcement

Project maintainers may remove comments, reject contributions, or block users whose behavior violates this Code of Conduct.
